# Interface Dashboard ÉcoleDirecte

Interface utilisateur cockpit pour le tableau de bord ÉcoleDirecte, développée avec React 19, TypeScript, Vite et Tailwind CSS.

## Fonctionnalités

- Bento Grid responsive conçue pour un affichage plein écran (100vh).
- Auto-défilement ping-pong intelligent avec détection du survol et du toucher.
- Thème clair soigné avec badges colorés par discipline scolaire.
- Bascule dynamique de l'emploi du temps entre aujourd'hui et demain.
- Validation instantanée des devoirs et bascule du statut de lecture des messages.
